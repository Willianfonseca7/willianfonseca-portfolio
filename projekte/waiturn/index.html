Schwerpunktprojekt

WAITURN

  • Next.js, TypeScript, Prisma und PostgreSQL für Termin- und Warteschlangenverwaltung; Route Handlers, Authentifizierung, Rollenberechtigungen und Socket.IO-Echtzeitaktualisierungen.
  • Row Level Security per Migration in 27 öffentlichen PostgreSQL-Tabellen aktiviert; Zugriffe ohne Policies für Rollen ohne Bypass gesperrt. Mandantentrennung im Prisma-Backend über Session, Rollen und shopId.

Produktvisualisierung · vom Autor bereitgestellt

Problem

Terminplanung und spontane Warteschlangen sollen in einer Anwendung zusammenlaufen.

Umsetzung

Row Level Security per Migration in 27 öffentlichen PostgreSQL-Tabellen aktiviert; Zugriffe ohne Policies für Rollen ohne Bypass gesperrt. Mandantentrennung im Prisma-Backend über Session, Rollen und shopId.

Architektur & Stack

Next.js und TypeScript; Prisma mit PostgreSQL; Better Auth für Authentifizierung. Anwendungslogik, Datenzugriff und HTTP-Schnittstellen sind getrennt.

Technische Entscheidungen

Backend-Mandantentrennung über Session, Rollen und shopId. RLS sperrt direkten Supabase-API-Zugriff ohne Policies; es sind keine RLS-Policies pro Mandant implementiert.

Validierung

Unit- und E2E-Tests mit Vitest und Playwright implementiert (über 2.100 Unit-Tests).

Status

Aktive Entwicklung. Der Code ist privat; eine öffentliche Demo ist derzeit nicht verlinkt.

Nachweise

Technische Implementierung geprüft; Repository nicht öffentlich.
